# QCU · 分层练习

## 输入

教师提供知识点、共同学习目标、先备知识、每档题量、练习时间、允许的工具与课程规则。缺目标或用途时先问一句，确认是教师备课练习，而非正在进行的实际考核。只用匿名或合成学情。

## 步骤

1. 确定各档共同检验的目标，按支架、步骤数与情境迁移增加难度，不按学生身份或历史成绩固定分层。
2. 设计基础、进阶、迁移题；每题给预计时间、支架选项、常见误区及教师用评分要点。允许学生动态选择和切换。
3. 自行验算数值、单位与答案范围，检查题干信息充分且无歧义。教师用参考过程与学生题单分开展示；实际考核只提供设计原则，不给可绕过考核的答案卷。
4. 用相同目标建立评分尺度：概念、方法、解释分别观察；说明哪些错误触发补充支架。核对总题量与时间。
5. 列出教师需要审核的难度、教材一致性、无障碍替代与课程规则，不声称分层效果已验证。

## 输出

“教师审核草案”：共同目标、三档学生题单（题干/时间/可选支架）、独立教师参考区（评分要点/过程/误区）、切换建议、待确认清单。未知答案或规则明确标注，不猜测。

## 合成示例

输入：目标“用正确基数解释百分比变化”，每档1题，总计12分钟，纸笔练习。
输出片段：基础3分钟，100变110的变化率（支架：变化量÷原值）；进阶4分钟，110回到100，比较两次变化率；迁移5分钟，合成商品先涨10%再降10%，是否回到原价并解释。教师参考：10%、约-9.09%、最终99；评分观察基数选择及解释。所有数值为合成，供教师审定。
