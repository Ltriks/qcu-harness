# 城院 · 课程资料问答

## 使用前提

用户应在 DSH 工作区中放置课程资料。样例结构见本 skill 包内 `sample-course-materials/`（可复制到自己的课程目录）。

推荐目录：

```text
course/
  01-大纲.md
  02-讲义摘录.md
  03-习题.md
```

## 规则

1. **先检索本地资料**再回答；引用时写明文件名与小节。
2. 资料没有的内容：回答「资料未覆盖」，给查找建议，**不要编造学校通知或分数规则**。
3. 作业类问题：只解释要求与评分点，不直接给可提交全文。
4. 若工作区没有资料，引导用户放入文件或粘贴相关段落。

## 回答结构

```markdown
## 依据
- 来自：`文件名` …
## 解答
## 仍不确定
- …
## 下一步自学
- …
```
