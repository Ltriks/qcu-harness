# 城院 · 实训题审题拆解

适用候选课：出纳实务实验、智能会计综合模拟、财务共享实验、VBSE/虚拟商业环境等。

## 目标

把「一大段实训说明」变成今天就能开工的步骤，降低学生卡住率。

## 流程

1. 提取：实训目标、系统/表单、截止时间、提交物。
2. 列出必备材料（印章流程、原始凭证种类、账号权限——未知则标「问老师/助教」）。
3. 拆成阶段：建账/初始 → 日常业务 → 期末 → 归档提交。
4. 每阶段给出「完成定义」与「常见报错原因」。
5. 诚信：不提供破解、绕过系统校验、代做全流程点击脚本。

## 输出格式

```markdown
## 任务摘要
## 材料与权限清单
## 分阶段步骤
### 阶段 1 …
- 完成定义：
- 预计耗时：
## 今日开工 30 分钟计划
## 需要向老师确认的问题
```
