# 第一次使用：DSH 与 QCU 市场安装指引

P9 `0.1.0-pilot.9.1` 已完成本地审查，尚未发布到Hub。当前电脑可使用已核验本地TGZ自行验收；mini/其他电脑需先取得同一固定包或等待另行确认的Hub发布。请先读[父线程交付检查](qcu-market-p9-parent-validation.md)，拿到确认的固定包后再执行市场安装。历史 P8 的发布链接见 [P8发布记录](qcu-market-p8-hub-deployment.md)，不能将它当成 P9。市场中的“新手指引”需要市场已经安装才能打开，不能替你安装 DSH。

1. **准备官方应用。** 当前支持范围为官方 DeepSeek Harness `0.2.0-rc.2`、Apple Silicon Mac。可从[官方桌面入口](https://deepseek.com/harness/)了解安装包来源；该入口的最新下载不自动等于本轮支持版本，请先由团队核对为 `0.2.0-rc.2`，版本说明见[官方固定发行记录](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.0-rc.2)。使用团队确认的官方Apple芯片安装包，按安装窗口提示将应用放到“应用程序”，再普通打开。本文没有重新下载或验收官方安装包，也不引导绕过系统安全提示。其他系统与版本未在本轮验收。无需终端、专用启动脚本或新建测试 Home；使用自己的正常环境，不复制他人的配置或凭据。
2. **确认局域网条件。** 学校已有 LAN Hub；需能连接其所在局域网。请维护者提供本次发布确认。P9 Hub下载链接：**待发布确认**；本地固定包路径和SHA256见[父线程交付检查](qcu-market-p9-parent-validation.md)。本次固定包43446字节，SHA256为 `ecdc4373baad4de8415c27a6b04aa31b9e01ae516a6e3e972660a32bd7108e12`；不要把初次审查前候选当作当前交付。不要猜测 URL、照搬旧市场哈希或下载来源不明的包。
3. **安装市场。** 拿到确认的 P9 TGZ 链接或本地文件路径后，打开官方“插件”，选择“添加插件”，在“包名或地址”填入该链接/绝对路径，检查名称、版本和来源，再按官方“安装”流程操作。出现脚本授权、失败、未知结果时先停止并请维护者核对，不自行扩大权限或自动重试。安装后查看市场包及其组件的状态，按官方界面启用；如提示“更改将在下次启动生效”，正常退出并重新打开 DSH。市场包与教学技能是各自独立的包。
4. **配置自己的模型。** 打开官方“设置” → “模型”，按自己选择的提供商在“API 密钥”中填写自己的 Key 并保存；需要时使用“添加模型提供商”。Key 只输入官方设置，不贴到市场、反馈或截图。模型调用使用本人账号并可能产生费用。配置状态不等于请求成功，首次任务仍需实际验证。
5. **完成第一项任务。** 打开“QCU市场”，可先浏览“新手指引”。在“常用任务”选择“备课教案”，填入完整合成示例，查看对应技能详情；未安装时先下载并审阅，再“确认安装（保持未启用）”。安装后另行“查看启用确认” → “确认启用”，一次覆盖本包与唯一组件。按提示自己重启。返回常用任务，生成、审阅并复制任务文本；手动新建对话，选择真实 `/qcu-lesson-planning` Skill，粘贴并自行发送。若找不到该 Skill，先核对启用与重启，不能把普通文本当作已选 Skill。教师检查输出中的知识、时间、评价与来源；不直接使用未经审阅的草稿。

“组件已加载”、生成或复制文本、“已浏览引导”都不证明模型配置、授权、真实技能调用或教学验收通过。按 [用户验收表](qcu-market-p9-user-acceptance.md) 逐项记录。三项模板只处理匿名文本，没有文件上传；草稿留在当前市场页面内存，清空/卸载/重载后移除，内部返回保留任务草稿。反馈离开页面即清除，没有自动提交。

以上关键菜单文字已由父线程按固定官方rc.2 ASAR代码核对，公开依赖源树语言文件仅作补充；并非本轮真机截图或实际菜单位置测试。不同语言或版本位置可能变化。不能代替官方设置操作，不提供全应用锚定教程。
