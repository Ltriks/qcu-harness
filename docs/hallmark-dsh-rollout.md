## 使用

其他机器在工具市场刷新目录，找到 Hallmark 页面设计，核对后安装，再单独启用。

mcumacmini（192.168.1.19，SSH 使用 mcumacmini 用户）已经完成安装和单独启用；用户已正常退出并重新打开 QCU，随后核对到新进程、正确版本及选中状态。

在自由对话选择一个用于生成网页的工作文件夹，输入：

```text
/qcu-hallmark-design
为普通10至11年级学生做一个指数法则复习网页。
用途：老师投屏、学生课后复习。
风格：Dusk；保留清楚的文字对比和键盘操作。
内容：三个知识点、两道自检题、可展开的答案。
使用合成示例，不编造学校资料或学生成绩。
生成可在浏览器打开的页面，说明实际完成和未完成的检查。
```

技能适用于新页面，以及用户明确指定的 Hallmark 改版或审查。它不保证消除所有 AI 风格；输出仍需内容审阅。
