# 独立专家库与团队界面升级

2026-10-23，版本 `qcu-expert-teams@0.2.0-pilot.1`，协议2，存储schema2。用户反馈要求专家独立配置、团队选择专家与协作配置，并改善原型感及交互流畅度。

## 当前实现

- 专家库独立保存名称、简介、职责和最多4项已安装技能；支持新建、编辑、复制、归档和恢复。
- 团队成员通过expertId引用专家，并保存团队专用分工。支持独立评审后汇总、顺序接力、自定义依赖和1–3人的并发上限；同一专家可供多个团队复用。
- 紧凑的专家团/专家库/运行记录导航，搜索主列表和详情区；任务与团队配置分开，技能和依赖按需展开。成员选择弹窗自动聚焦搜索，编辑未保存切换受保护；运行记录默认打开最近一次结果。
- 唯一或上次合法工作区自动选择；同一工作区重连保留未保存草稿，并废除旧运行确认。配置编辑与运行历史相互独立。
- 导出自包含团队与专家；导入时重映射id，创建新对象。引用中的专家不能归档；团队和专家归档可恢复。
- 专家修订会使旧预览失效，运行保留职责、技能、输入和模型快照。没有新增运行依赖，模型仍共用DSH默认设置。
