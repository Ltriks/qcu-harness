# 会计系技能一键包示例

2026-11-16。目标：市场中一个教学试用包，一次安装与一次明确启用后，得到四项可独立使用、收藏及固定到首页的技能，以及一个选用入口。适用本科基础会计教学示例，课程范围待会计系教师补齐。

## 产品约定

- 市场条目：“会计系教学技能包（示例）”，展示包含清单、适用场景、版本及未验收项。
- 四项成员：会计分录实训、凭证审核模拟、报表勾稽练习、课堂案例设计。统一入口只作选用与引导，不声称自动组织多Agent。
- 一个包注册多个命名技能；不是把所有内容塞进一个巨大提示词，也不是一次下载安装多个来源不明的插件。
- 安装沿用现有来源、大小、SHA256、官方inspect与启用确认。包内技能统一升版和启停；首页取消固定不卸载、不停用。
- “我的技能”可按成员独立启动，后台仍归属同一个已安装包；管理安装指向包。使用技能与包安装身份分离，保持原有单技能包兼容。
- 首轮无新工具权限、无后台进程、无外部服务或账套连接。教学数据全部虚构；不代做真实财税处理，不将技术通过写成教师认可。

## 阶段和验收

1. 编写技能、包清单和一套有标准答案的虚构数据；确定性验算借贷、余额、利润与报表关系。
2. 以官方provider实现原子多技能注册、冲突拒绝和停用释放；固定每个成员的内容摘要及资源路径。
3. 扩展“我的技能”和首页，识别包成员与母包关系；不依赖修改签名市场schema来假冒多个安装包。
4. 官方SDK验证发现、内容获取、资源、启停；界面验证成员独立使用和管理归属；不调用真实模型冒充教学验收。
5. 按现有市场投稿/审核/签名发布流程交付试用条目，验证下载和隔离安装；不覆盖既有市场条目或老师文件。内网发布与GitHub推送、整包Mac/Windows重打分别记录。

首轮局限：包内技能不能独立升级或停用；需要独立维护时可改为独立产品加安装集合。系名是面向老师的入口分类，不是模型权限隔离或数据隔离。正式扩展前需系内负责人确认技能清单、教材/准则口径、输出样例和维护人。
