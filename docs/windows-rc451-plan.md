# Windows rc4.5 hotfix与市场交付取舍

2026-11-17用户反馈：官方内核升级入口仍在；市场报process.getuid；希望复用腾讯云市场或提供离线安装。既有离线包已预装市场16.14及18组件，但目录仍连内网.68。此前只迁移诊断与查询，没有迁移市场。

推荐 pilot：云端签名市场为主、预装/离线安装为兜底。现有腾讯云IP HTTPS和Nginx已验证，可独立提供只读签名目录和固定归档，不开放维护后台、上传或私钥；签名留在既有发布环境。离线预装继续可用，不把离线目录当成新鲜在线安装授权。

|方案|教师使用|维护与限制|
|---|---|---|
|腾讯云静态签名市场|校外可发现、下载安装；同一入口|复用现有HTTPS与服务，需签名期限维护和同步发布；不需要新增数据库|
|纯离线可安装市场|无网络可用|每次扩充须再发整包/目录与归档；版本和撤回传播慢，不能解决getuid平台缺陷|

实施顺序：1修Windows权限检查与目录持久化，保留POSIX保护/Windows ACL。2移植冻结运行时的受管升级保护，隐藏官方按钮且后台拒绝check/download/install，保留官方最低版本政策。3隔离上线云端只读目录和不可变归档，验签与安装实测。4预装能力断网回归；修复版本保持旧tag不可变，现有用户配置和模型保留。5新包必须从Windows本地磁盘实际解压、启动、重开及市场安装验收；发现UNC路径给出可执行的本地复制提示。

通过条件：Windows没有getuid异常；错误ACL/链接拒绝；模拟点击无法调用官方更新；公网签名目录与包摘要通过；首次加载无需手动刷新；离线已装功能可见；原配置不变；实际GUI/退出重开记录与后台测试分开。发布与修复进度以本分支新证据为准，本计划不是验收结果。
