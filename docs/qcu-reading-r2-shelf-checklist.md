# R2 资料架 · 教师短清单

仅适用于后续经维护者批准安装的 `qcu-reading@0.2.0-pilot.1`。本轮是本地候选，未安装到真实 DSH；以下真实教师步骤尚未验收。

1. 选对工作区，导入一份自编材料。原文件保留，阅读的是本地快照。
2. 展开“整理与管理此版本”，填写可选标题、课程 / 分类、标签并保存。核对原文件名和版本仍在，旧回答的来源按钮仍打开旧版本。
3. 在左侧按课程、标签或“只看收藏材料”筛选；用“资料架关键词”查文件名、标题或原文字词。无结果时点“清除筛选”。这些操作不调用模型。
4. 选中段落并保存摘录，在“已保存摘录”里点“收藏摘录”，再从左侧“收藏摘录”打开对应原文。
5. 展开“本地备份”，阅读包含原材料及问题 / 回答的说明，再点“下载完整备份 JSON”。文件存到本机；本版仅导出，尚无导入恢复界面。请妥善保管，不把问答 Markdown 当成完整备份。
6. 需要移除测试材料时，点“预览删除此版本”，核对原文件、SHA-256 与摘录 / 问答数量。先试“取消删除”或 Escape，确认记录仍在。确需移除才点“确认删除此版本及记录”；会连带删除该版本的摘录、问答和整理信息，界面无法撤销。真实资料删除须由本人决定。
7. 重开后核对分类、收藏和历史引用；切换工作区后检查无其他工作区的材料或备份混入。

R1 不能读取 schema 3。升级后的第一次写入会先逐字节保留原 schema 1 / 2 状态；回退会损失备份之后的记录，须停止插件并请维护者核对。不要自行降级覆盖当前状态。扫描 PDF、复杂版式、公式、图片与 Word 修订仍须对照原件复核。生成问题仍须逐次核对片段并明确确认发送；来源可定位不代表回答正确。
