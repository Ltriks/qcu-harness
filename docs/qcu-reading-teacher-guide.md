# QCU 材料伴读：教师内部试用说明

本轮适用Apple Silicon Mac内部试用，Windows尚未验证。本说明对应正在准备发布的材料伴读pilot.4及支持它的新版QCU市场。当前仍处于内部验证阶段，Hub尚未上架；请以维护者通知的固定版本为准。

材料伴读用于阅读已有资料、查找原文、保存摘录，并围绕资料向模型提问。材料和阅读记录保存在本机工作区。调用云模型时，确认页列出的本次问题与片段会发送给显示的服务方，并可能使用自己的模型额度。

## 第一次打开

1. 安装并打开部门提供的QCU助手，按已有使用指南配置自己的模型。不要把API Key发到群聊、反馈或聊天窗口。
2. 市场正式上架后，在“插件市场”找到“材料伴读”，阅读用途、兼容性、来源和权限后安装；再按界面说明确认启用。安装、启用、问答发送分别由你确认。
3. 若界面提示下次启动加载，通过应用菜单正常退出再重开；工具插件更新与官方DSH应用升级是不同入口，本试用沿用内部指定的DSH版本。
4. 从左侧“维护与高级选项→材料伴读”进入。选择这门课的工作区；新建工作区后可点选择框旁的“刷新”。

## 用自己的资料试一次

1. 点“导入材料”。建议先选一份自编或已脱敏的小文件：TXT/Markdown每份不超过256KiB，文字型PDF/Word每份不超过2MiB。
2. 阅读原文与提取说明。PDF显示物理页；Word按章节、段落和表格行列定位，不显示虚构页码。图片、公式和扫描PDF可能缺失，须对照原件；当前没有OCR。
3. 在搜索框输入原文中出现的关键词，点击结果返回原文。例如自编会计表格中可以搜“盈亏平衡”。当前按字词匹配，跨文档语义检索尚未提供。
4. 点击段落或表格单元格，保留需要的摘录文字，填写自己的笔记并点“保存摘录”。阅读、搜索、保存笔记不调用模型。
5. 输入包含材料关键词的问题，再点“准备问答”。例如“盈亏平衡销量是多少？”应先核对确认页是否真的包含项目名称和对应数值。
6. 阅读确认页中的实际模型、问题和完整片段。只有同意本次发送，才勾选并点“确认发送”；也可以取消返回阅读。不要因等待而重复点击生成。
7. 点击回答的来源标记，核对它实际对应的原文。回答是教师审阅草案，来源可定位不代表推理自动正确。
8. 点“导出Markdown”并选择保存位置，保留本次问题、回答、确认片段与材料版本。关掉应用后，已保存的摘录和问答记录仍可从原工作区打开。

## 常见情况

| 情况 | 建议操作 |
| --- | --- |
| 找不到刚添加的工作区 | 在伴读顶部点“刷新”，再明确选择工作区。刷新不会发送问题。 |
| PDF看不到文字或提示需OCR | 先核对原件是否为扫描图；换用可选中文字的版本，或在外部完成OCR后再导入。 |
| Word中的公式、图片或复杂表格提取不完整 | 查看提取说明并对照原件；只使用已核对的正文与表格片段。 |
| 准备问答没有找到依据 | 换用原文中出现的关键词，检查确认片段，不把未找到依据当成模型结论。 |
| 模型调用失败或超时 | 保留提示和已保存记录，先检查自己的模型服务状态；重新发送前再次核对本次内容与费用。 |
| 需要反馈问题 | 通过新版市场的问题反馈入口说明版本、文件类型、步骤和提示。内部试用请用自编案例复现，不附Key或真实师生资料。 |

## 试用时重点看什么

- 原文、表格数值和定位是否对应；同一个文件重复导入是否只打开原快照。
- 发送前能否看清本次模型与片段，取消后是否确实没有生成。
- 点击引用是否返回正确位置，导出后能否找到来源和材料版本。
- 保存的笔记与问答重开后是否仍在，切换工作区是否保持资料隔离。

个人资料架、题库、多文档语义检索和OCR尚未随本版交付；后续按独立阶段增加。
