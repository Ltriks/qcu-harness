## 实现与范围

现有首页顶部提供三步：取得团队确认的官方 DSH → 复制固定市场地址 → 打开 DSH，在“插件 → 添加插件”粘贴并审阅安装，另行启用/按需正常重启。只有点击才复制或唤起；`dsh://open` 只打开窗口，不携包、不定位安装面板、不绕过确认。没有独立程序、终端、Python/Node 或测试 Home 前置。

HTTP 复制失败保留可见只读地址、选中并提示 ⌘C / Ctrl+C；只在 Clipboard Promise 成功后提示已复制。目录失败或长期等待不影响首次安装入口，目标 URL 不受目录或浏览器上下文覆盖。备选 TGZ 无需解压，Finder ⌥⌘C 获取真实路径，长期保留文件。完整性错误停止联系维护者，网页不修复已有坏锁。

业务文件仅 `hub/web/index.html`；新增 15 项入口测试，修正一个既有测试的夹具条目数断言，更新相关导航和指南。服务代码、路由、manifest 验证器、目录、市场源码、准备器源码/应用说明、安装包均未改动。主仓库已有 README 与 onboarding 用户验收填写保持原字节。

## 使用者验收步骤

1. 打开当前本机预览。查看“教师从这里开始”，展开/收起两个说明区；主界面应只保留三步操作。
2. 点击“复制市场安装地址”，粘贴到自行新建的空白文本中，确认完整地址指向校园 Hub 的 qcu-market 0.1.0-pilot.9.1 固定 TGZ。自动复制不可用时按提示手动复制；不发送或暴露原剪贴板内容。
3. 需要实测唤起时，确保目标是正常默认 DSH，再点“打开 DSH”，由本人处理浏览器询问；应只显示 DSH，不自动安装。若无响应，手动从应用程序打开。
4. 已有有效 P9.1 的环境不重复安装。新机器验收需用户选定真实环境，按[教师指南](qcu-hub-teacher-install.md)首次安装、另行启用并按需正常重启，之后检查 DSH 内市场；不要为补证据重建 mini 测试 Home。
5. 备选下载无需解压；记录通过、失败和未测试，不把 URL 复制、包下载或助手口头成功当作安装/启用通过。遇到完整性错误保留并联系维护者。
