# 工作助手入口 · 试用版

2026-11-16。用户确认把“我的技能”改为“工作助手”，按工作目标组织入口，不再只按技能名浏览。组件为市场16.12、主题0.3.0-pilot.5；现有会计系技能包归档未修改。

## 使用方式

默认进入“材料写作”，选择“开始处理”，补充工作文件夹及材料，点击“打开对话草稿”，在对话里检查模型与内容并手动发送。可搜索任务、只看收藏，或固定到首页。切换分类不会清空各任务已填材料；离开页面后的表单不承诺持久化。

2026-11-17（market 16.14）：首页所有对话型常用入口统一直接打开对应任务的对话草稿。首页已填材料时一并带入；空白时也直接打开，并预填任务名称、处理要求及“我的材料与要求”区域，便于继续补充。办公任务不再绕到工作助手表单。均不自动发送、调用模型或覆盖已有草稿；无可用工作文件夹时明确提示。工作助手内的详细表单仍可用于先整理材料再进入对话。

## 分组与真实能力

| 分类 | 本轮入口与范围 |
|---|---|
| 材料写作 | 内置润色材料、起草通知；已安装的引用自查也归此类 |
| 会议纪要 | 内置文字纪要和待办；已安装的教研简报归此类 |
| 表格分析 | 内置表格文字、数据问题与统计口径梳理；计算及文件读取以实际工具为准 |
| 汇报准备 | 内置汇报提纲、逐页要点和待补材料，未声称自动生成PPT文件 |
| 教学准备 | 现有教案、分层练习、教材、笔记、网页等已安装能力 |
| 科系专区 | 会计系包的选用入口与四项成员，管理安装仍指向母包 |

前四组的五项办公入口是内置“对话任务”，不是偷偷安装的新DSH技能。它们整理材料与要求，使用当前对话模型，不启动模型、不自动发送、不增加工具权限。文档读写、计算与导出均以进入对话后实际可用的能力及审批为准。

安装技能的底层名称、母包与安装管理收在“能力说明”；任务标题按能完成的工作表述。原技能的调用标识、内容、启停和收藏ID保留。未启用技能不可启动；已安装清单读取异常时，内置对话任务仍可用。
