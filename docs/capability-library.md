## 使用方式

侧栏新增 **能力库**，提供“技能 / 专家团队 / 其他插件”三个平级分类。工具市场使用相同分类。当前列表展示市场收录项目，包含未安装项目，不声称已覆盖所有手工配置的 DSH 技能。

专家团队与普通技能分开；五套迁移团队及原有文字评审插件归入专家团队分类。原生团队展示角色数、来源、用途、交付物、安装/启用状态及试用提示。未安装或未启用时不能启动，可进入市场详情安装或管理。

点击“开始任务”后填写工作区、目标、可选的资料路径或说明。再点击“打开任务会话”，通过官方 Session Controller 创建独立会话、预填技能调用和任务内容、导航到主会话。**不会自动发送、调用模型或读取上传所填路径中的文件**。由用户在主会话发送后执行，可以继续加附件或修改内容。

旧文字评审项提供“打开文字评审”，继续进入原有插件，不交给原生工具团队启动器。旧侧栏专家团入口暂保留兼容；本次未修改该插件、其配置或运行记录。
