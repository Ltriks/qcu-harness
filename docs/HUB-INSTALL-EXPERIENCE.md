1. 首页在没有独立 Skill ZIP 时直接显示 **插件 Plugin**。找到固定版本，下载 TGZ；卡片同时显示版本、SHA256 和精确兼容版本。
2. 展开“安装到官方 DSH：分步指令”。将哈希与独立收到的可信来源对照，不以同源字段作为来源证明。
3. 可选：Mac Finder 选中刚下载的 TGZ，按 **⌥⌘C** 复制完整路径，粘贴到卡片输入框。不需要手工拼接用户名、文件名或下载目录。网页不会读取这个文件或路径，不上传、不保存路径，也不声称已核验。
4. 点“复制校验/安装指令”，粘贴到官方 DSH。未提供路径时指令要求先在已授权范围取得用户选定文件的真实绝对路径，无法取得就询问；不猜 Downloads，不把 URL 直接当 install_bundle target。实际文件字节/版本/哈希一致之后才请求官方管理器安装。保持 workspace-write+ask，每次真实工具卡只允许一次，拒绝或缺工具即停止，不擅自开启工具、不使用版本豁免、approvedBuilds 或永久权限。
5. 正常退出并重启 DSH，再复制“重启后查询/启用指令”。用真实 list_plugins/list_bundles 返回的完整 entryId，确认来源与固定版本后，另次批准 set_plugin(enabled=true)，再次正常重启。网页不猜运行时 row id。
6. 复制“再次重启后调用指令”，展开真正 Skill 或插件工具结果。学习教练固定 p1 对应 chengyuan-study-coach；未知版本的插件只给实际功能验证提示，不猜 Skill 名。下载或助手自述不等于安装/调用。
