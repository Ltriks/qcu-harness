用户已确认将“我的技能”改为“工作助手”。默认展示材料写作，页内按材料、会议、表格、汇报、教学及科系分组；五项内置文字办公任务可打开普通对话草稿、收藏和固定。技能名称及安装管理收进能力说明，原有技能/会计包的身份与状态校验保留。使用说明、能力边界和证据见 `work-assistant-entry.md`。

## 我的技能入口修订（主题pilot.3 / 市场16.10）

按确认的分工，侧栏“我的技能”只展示本机已安装的普通QCU技能，任务输入和启动草稿在本页完成，不借道市场。收藏、只看收藏、首页固定与本机清单共享偏好；获取新能力才进入工具市场；管理安装进入官方包详情。专家团队保留专用入口。

安装状态从官方本机管理器读取，与市场刷新解耦；首页普通技能也优先使用本机状态。具体范围、验证证据及文件型自定义技能未覆盖的边界，见 `capability-library.md` 的2026-11-16检查点。旧导航遮挡修复继续保留。

## 导航布局修订（0.3.0-pilot.2）

用户实机反馈底部独立箭头错位，以及Mac侧栏收起后的顶部导航遮挡首页。读取随包官方布局/渲染器源码确认：Mac收起宽度为0，`data-shell-leading` 绝对定位于顶部；原预览使用64px图标栏，未覆盖真实布局约束。

修订将收起/展开控制移到品牌行，删除底部独立箭头；底部只有带省略号图标的“更多”。顶部浮动导航只保留展开按钮，不重复“首页”。通过公开 `data-slot="main"` 锚点给Mac主内容列预留56px实际布局空间，覆盖普通/全屏；不依赖供应商生成类名。收起后不可见的Mac侧栏设为inert/aria-hidden，避免键盘和辅助技术进入隐藏控件。菜单支持Escape、点击外部及换页关闭。

新的浏览器预览按官方0宽侧栏、绝对导航槽和display:contents主槽建模；普通Mac、全屏、390px窄窗口均断言标题在按钮下方至少12px，无横向溢出，并验证展开恢复。3项偏好/实际Cordis连接测试通过，Impeccable扫描无发现。预览和坐标证据：`.work/home-navigation-preview/`。此证据仍是按官方约束建模的浏览器验证，不冒充原生窗口人工验收。

## 推荐结构

侧栏“教学首页”改为“首页”，删除独立“教学工具”入口。现有教学任务提示词示例迁入“使用指南 → 新手教程 → 任务示例”；保留匿名示例编辑、工作文件夹选择、打开草稿和手动确认发送。原入口兼容跳转到教程示例，避免旧链接失效。

首页以对话为主：中性标题和空白输入框，选择工作文件夹，打开对话草稿，由用户检查后发送。下方为“我的常用”和“最近对话”。不再默认选中备课任务或注入教学提示词。新手指引保留为轻量入口，详细步骤不常驻占用首页。

“我的常用”支持老师从技能中主动固定入口，后续可以扩展工作团队和已注册页面。收藏是个人能力清单；固定到首页是对该清单的精选，两者分别操作。最近使用只形成独立历史，不自动固定到首页。首次没有固定项时提供“去技能中添加”，不冒充个人收藏；新手示例在教程中展示。

## 交互约定

- 技能列表提供“收藏”和“固定到首页”，已固定时显示状态并可取消。
- 首页提供“管理常用”，可调整顺序、移除和选择显示项；移除入口不卸载能力，不删除历史。
- 点击技能打开带正确技能标识的可编辑对话草稿；点击工作团队打开该团队的任务页，不伪装成普通技能对话。
- 对未安装、已禁用或已删除的能力显示真实状态和处理入口，不自动安装、启用或运行。
- 首页与技能页共享同一份本地偏好，重启保留。收藏保存稳定能力标识和顺序，不复制技能正文或对话资料。不承诺跨设备同步。
- 日常操作保留清晰加载、空态、保存失败和不可用提示；键盘可操作，窄屏不隐藏主要对话按钮。

## 技术现状与实施顺序

改造前已检查教师主题 `tools/teacher-branding/src/view.mjs`（旧构建源位于 `.work/qcu-desktop-iteration-20261110/`）：首页、示例任务、最近会话及教程已有实现。市场能力库源为 `hub/plugins/qcu-market/src/capability-library.mjs`，当时未见统一收藏/首页固定接口。本轮新增共享偏好接口，不能仅改首页文字就声称收藏可用。

1. 统一首页命名，迁移示例至教程，保留旧入口兼容。
2. 以现有真实技能清单接入本地偏好与首页固定项，不另维护一份硬编码技能列表。
3. 接通对话草稿与最近会话，处理未安装/禁用/失效的固定项。
4. 验证技能页与首页状态一致、保存失败、重开保留、取消固定不卸载、正确草稿路由及窄屏交互。
5. 先交付Mac候选验收，再同步Windows并分别打包；当前现用安装包不因计划落盘而变化。

此文为本轮讨论建议；业务结构优先，沿用现有清蓝视觉，不作为另一次全站视觉改版。
