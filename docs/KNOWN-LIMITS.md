# 已知限制

固定入口和匹配官方 baseline 上的启动策略已在候选测试中覆盖；普通独立 DSH 安装业务包仍没有同等策略保证。策略不构成任意同权限 Node 代码的操作系统沙箱。

新的 Host 管理路径已加入父管道退出清理；Linux 合成强杀与重启验证见 [生命周期说明](HOST-LIFECYCLE.md)。旧版已经遗留的活 Python 不自动接管或终止，文件被替换或异常 I/O 仍可能要求人工核实。新原生 GUI、实际存储擦除、系统选择/下载/打印、Windows ACL、安装共存、签名、更新与回滚、稳定 profile 迁移及 Hub 安装链仍未验收。旧 Mac 的人工操作通过仅适用于旧版，不认证本候选。

本次三方核对后合入旧 Mac 的网页检查完成反馈：候选三文件与修复前基线一致，只更新对应 web 文件、资源哈希及 DOM 回归；新原生视觉效果仍未验。演示/个人规则不等于学校正式规范。未使用真实论文、学生资料或付费模型。

仓库来源是候选 v1 加已审查的网页反馈增量，并非原 v1 包的逐字节副本。本轮没有生成新的正式包或发布版本；后续打包发布须分配独立版本，不能覆写旧候选 TGZ。
