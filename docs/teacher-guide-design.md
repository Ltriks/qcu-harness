# 教师离线指南设计与内容约定

对象是首次使用AI助手的教师。目标是无需Hub、终端或安装插件，先配置自己的模型，再完成一次可审阅的备课练习。

配色：校门蓝 #174F91、正文墨蓝 #17324D、纸白 #FFFFFF、浅蓝底 #EFF6FC、分隔线 #CCDCE9、完成绿 #206346。沿用已确认的校门与书页图标。标题使用本机宋体族，正文用本机中文黑体族，18px起；不下载字体。

布局：左侧常驻章节导航，右侧左对齐的单栏手册；首页以“打开助手／接通模型／完成备课”三步练习为主视觉。手机变为顶部换行导航。正文行宽控制在约36个汉字，表格允许横向滚动，打印展开折叠内容。

初稿审视：删除仪表盘、统计数字和重复卡片；只有实际的首次操作使用序号。技能采用展开说明和可复制的合成示例，重点是输入、预期结果与教师核对点。API Key只在助手内填写，指南不提供密钥输入框，不读取或持久化用户信息。

内容依据：冻结教师rc.3中实际七项Skill正文、课程工作台0.1.0-pilot.1.2及飞书工具0.1.0-pilot.1.1说明；随包官方客户端0.2.0-rc.2模型设置代码及本机正在运行界面。内置DeepSeek使用Anthropic Messages兼容地址；自定义接口必须核对协议。服务商资料核对于2026-10-22，页面附官方链接。

验收：HTML单文件、无网络资源依赖、无真实密钥、内部锚点和复制按钮目标有效；浏览器可直接file打开，导航/复制/打印可用；两平台新归档保留旧应用、seed、启动器字节及ZIP权限/链接信息，Windows文件清单更新。模型调用与飞书授权不在本次验收范围。
