## 固定边界

- 每位教师电脑独立运行，材料、摘录、题目及使用状态保存在其本机工作区；运行不依赖 mini、Hub 或 DeepTutor 服务。
- 沿用官方 DSH 0.2.0-rc.2，通过 JavaScript + React 插件与 Skill 扩展；本轮不做 JS→TS 迁移，不改官方源码。
- 模型通过 DSH 现有服务调用，用户自备 API Key；插件不读取或另存 Key，不默认要求安装 Python、Docker、OCR 或本地大模型。
- Hub 只负责后续审核、固定包下载及升级。候选通过验证后，部署和安装另行安排；不覆盖旧包，不修改现有签名目录或扩大权限。
- 课程工作台由同事维护；主题、专家团和官方升级策略本轮不改动。市场仅做伴读产品准入和独立签名更新通道，不重做界面或扩大旧版策略。
- 单机运行不等于完全断网推理：使用云模型前，明确展示模型和本次待发送的资料片段，由用户确认。导入、浏览、搜索、摘录和导航不调用模型。

1. Node核心：导入限制/重复/同名不同内容、定位与搜索、落盘重开、非法路径/符号链接、容量、准备与确认绑定、模型变更、取消、失败、引文合法性和导出。

4. 精确TGZ：可重建打包，成员清单与SHA256、解包后关键回归；不替换不可变旧产物。
5. 原生验收：后续按包安装、启用、重开和文件选择核验；真实模型须由用户在DSH配置并确认一次资料发送。安装/启用与资料发送为不同确认。
