# 城院助手 rc.4.5.1 · Windows 热修试用版

版本 `0.1.0-rc.4.5.1`，构建 `rc45.2`，固定官方 DSH `0.2.0-rc.2`。源码标签 `qcu-teacher-v0.1.0-rc.4.5.1`。本次仅 Windows x64；Mac 保留 [rc.4.5](../0.1.0-rc.4.5/README.md)。

## 本次修复

- 修复工具市场在 Windows 报 `process.getuid is not a function`。使用 Windows 实际 SID/ACL 检查，保留 POSIX 权限检查，拒绝不安全共享权限及链接。
- 增加官方 Harness 内核升级入口隐藏逻辑，同时在后端阻止自动/手动检查、下载与安装，保留官方最低版本政策。QCU 后续使用完整套件更新。
- 工具市场目录和固定安装归档改用既有腾讯云 `https://111.229.103.201`，无需连接校内 `.68` 即可发现和下载安装。应用错误诊断与维护查询继续使用该云服务。
- 保留18项预装组件，首次离线准备及使用已安装能力不依赖在线市场。在线模型与联网工具仍需本人账号和网络。

## 下载与安装

下载 Release 附件 `QCU-Teacher-0.1.0-rc.4.5.1-win-x64.zip`，不要将自动生成的 Source code 当作安装包。

1. 先正常退出旧版城院助手，包含托盘后台实例。
2. 将 ZIP 完整解压到 Windows 本地短路径，例如 `C:\QCU451`。不要使用 Mac 共享目录 `\\Mac\Home`、网络盘或过深目录；传统 Windows 解压工具可能因长路径导致解压不完整。
3. 打开解压目录中的 `QCU助手\QCU助手.exe`。不要只复制或运行单个 exe。

ZIP SHA256：`1a21ec877b74bdc7081bb2bdc12298ebe61b0d48596074f804c35e3bc686ea60`，403853508字节。

本热修沿用 `teacher/0.1.0-rc.4.5` 数据目录，应用内套件号仍可能显示 rc.4.5。已用正式 rc.4.5 的用户会仅更新受管市场组件，保留模型设置、额外插件和工作文件；手改过受管组件会安全拒绝覆盖。更早版本配置不自动迁移。不要删除配置来处理启动错误。
