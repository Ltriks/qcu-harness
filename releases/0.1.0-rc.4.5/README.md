# 城院助手 rc.4.5 · Mac 与 Windows

版本 `0.1.0-rc.4.5`，构建 `rc45.1`，固定官方 DSH `0.2.0-rc.2`。统一源码标签：`qcu-teacher-v0.1.0-rc.4.5`。

- 首页常用直接打开对应任务草稿；办公任务空输入也可进入对话补充，不自动发送。
- 工作助手按办公、教学和科系任务分类，支持收藏与固定首页；更多菜单收束设置与帮助。
- 市场进入自动加载，连接重置后重新验证，区分加载中、连接失败和空目录。
- 专家团区分模板与我的团队，可编辑职责、工具和流程，保留独立审查、进度与报告；修复工具控制文本被误作交付、执行限额及失败证据相关问题。
- 预装Hallmark、会计系示例包和五个社区改编团队；合计18项组件、18项可发现Skill。社区内容不等同WorkBuddy原版，不代表真人专家或已通过教师业务验收。
- 启动诊断和维护查询接入 `https://111.229.103.201`，默认关闭自动上报，断网本地保留；无密钥、对话或教学正文。

## 下载与使用

[Mac Apple Silicon ZIP](mac-arm64/QCU-Teacher-0.1.0-rc.4.5-mac-arm64.zip) · [Windows x64 ZIP](win-x64/QCU-Teacher-0.1.0-rc.4.5-win-x64.zip)。各目录的 `delivery.json` 和 `SHA256SUMS` 记录大小、摘要与验收边界。

完整解压再运行。Mac打开整个 `QCU助手.app`；Windows打开文件夹内 `QCU助手.exe`，不要从ZIP或Mac共享盘运行。新包数据位于独立 `teacher/0.1.0-rc.4.5`，不自动迁移、不删除旧配置。首次在设置中填写自己的模型账号，重新选择工作文件夹；收藏与对话设置不自动从旧版复制。

Mac仅临时签名，未苹果公证；本机构建首次打开被系统信任拦截，新包GUI打开与退出重开仍待用户在系统允许后验收。没有关闭或绕过Gatekeeper。Windows在Windows11 ARM虚拟机中运行x64启动器，不能代替原生x64硬件或学校终端验收。真实模型输出及教师业务效果仍待试用。

工具市场仍位于校内 .68，离线初始化与预装技能不依赖市场可达；这次迁移的是启动诊断和查询服务。课程工作台继续不预装。
