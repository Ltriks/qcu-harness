Limits explicit: <=64 files, <=1MiB/file except schema JSON <=256KiB, <=10MiB total decoded, envelope <=15MiB. Reuse checker safe_path and security scanning where meaningful. Reject links on disk/store ancestors; original handoff remains unchanged. Failed preflight leaves no admitted submission. Persistent startup recovery for interrupted checking/preparing must not auto-approve/retry unknown writes; mark honest recoverable failure. Use single process exclusivity lock, thread-safe serialization and atomic/fsync state writes. No symlink following or open-ended read/download routes.

HTTP diagnostics only fixed safe codes, no raw exception paths/materials/secret echo; nosniff/no-store/referrer policy/CSP with self scripts and no inline. Reason/title displayed textContent only. Bounded connection read time.
