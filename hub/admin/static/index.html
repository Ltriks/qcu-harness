导入与审核工作区

导入同事交付材料

选择完整 handoff 文件夹，包含 submission.json、TGZ 和全部证据。原文件夹不会被修改。

尚未选择文件夹

最多64个文件；单个1 MiB，JSON 256 KiB；总计10 MiB。只进行静态检查，始终需要人工审核。
