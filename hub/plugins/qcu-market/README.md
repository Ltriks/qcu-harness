## Review and consent

Browsing and search initiate no RPC. Opening/back navigation never installs or enables; leaving a pending review revokes its consent. Explicit status/preparation first checks Host version, protocol 3 and the exact catalog SHA256. Missing/stale Host stops before download and asks for a normal DSH restart; the market never restarts the app. Preparation downloads only a reviewed immutable release from `http://192.168.1.68:8080/plugins/<id-version-sha256>.tgz`, validates size/hash and obtains official inspect results. The in-memory five-minute receipt binds UUID, release key, catalog fingerprint, bytes and expiry. Returning or declining revokes review. No remote catalog, metadata hash or provenance grants installation permission.

Only **Confirm install (keep disabled)** uses the public `installBundle` with `enabled:false`, a new request ID and the reviewed registry. Before calling it, the flow rechecks Host, bytes, receipt, inventory and inspect result. Changed catalog, expiry, profile state, source/hash or registry invalidates consent. Each card has independent state; preparation, review, mutations and unresolved outcomes block operations on other cards. No automatic retry or compatibility/build exemption is added.
