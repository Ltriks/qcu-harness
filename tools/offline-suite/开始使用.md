# 城院 DSH 离线完整发布套件 0.1.0-rc.1

本套件为内测候选，按 Windows x64 与 macOS Apple Silicon 分开分发。包含官方 DSH 0.2.0-rc.2 安装器、自带运行时、七项 DSH Skill、课程设计工作台、飞书文档只读工具、QCU 市场，以及七项 WorkBuddy 人工导入 Skill。安装不需要 Hub、npm、Node、Python 或已有包缓存。

## 安装与启动

1. 解压整个套件，保留目录结构。先打开 `client` 中的官方安装器，按官方界面完成安装；首次系统确认按原提示操作。安装位置建议保留默认。
2. 正常退出已有 DSH 后，双击 `02-install-QCU`（Mac 是 `.command`，Windows 是 `.cmd`）。安装器核对文件完整性，再用客户端内置的官方安装机制安装全部十个固定包；安装后另问是否启用七项文字 Skill 与 QCU 市场。选择否也会保留已安装内容。
3. 双击 `03-start-QCU` 打开城院环境。首次欢迎页可按客户端提供的“稍后配置”继续，或填写自己的模型配置。默认 DSH 数据不会自动迁移到这里。
4. 课程设计工作台和飞书工具初始不启用。需要时在官方插件设置中分别启用包及其组件；工作台需选工作区、配置模型，飞书需本人正常授权和一个有权读取的文档链接。随包 CLI 的路径已预填，不携带他人账号。

请先完成随包《验收与限制》中的合成测试，再用于实际工作。安装完成后，可以把城院数据目录中的 `Start-QCU-DSH` 启动文件复制为快捷入口；以后不必一直保留原套件目录，官方客户端安装位置应保持可用。

## 数据位置

- Mac：`~/Library/Application Support/QCU-DSH/offline/0.1.0-rc.1/`
- Windows：`%LOCALAPPDATA%\QCU-DSH\offline\0.1.0-rc.1\`

该目录保留专用 profile、已安装固定包、自己的后续配置、安装回执和诊断日志。不要把使用后的目录重新打包分发。原 `~/.dsh` 和已有 DSH profile 不被复制或改写；套件本身不含开发者凭据、聊天或工作区。

## “离线”覆盖什么

离线覆盖安装客户端、安装全部城院包、加载本地技能和启动客户端。模型推理需要可用的模型服务；本套件不包含模型权重，联网模型按本人账号使用。飞书本身是网络服务，本人登录授权、读文档必须能连接飞书。

QCU 市场保留原在线目录和主动检查更新能力。基础包已通过本套件安装，首次安装无需访问 .68；离开原局域网时，在线下载和检查更新会显示不可用，不影响已安装内容。此次固定包不被改写为离线市场的新版本。

## WorkBuddy 手工导入

打开 `workbuddy` 中的总包，解压后从其 `skills` 文件夹逐项上传单项 ZIP。先导入“备课教案”，按其中的《试用与验收》核对实际加载与回答效果。外层总包不是单项技能；本套件不含 WorkBuddy 客户端，也不自动操作其窗口。

## 版本与故障

本套件冻结已发布固定版本：QCU 市场 14.1、课程工作台 1.2、飞书工具 1.1 及七项 Skill；未将尚未发布的工作台 1.3 候选混入。精确版本和 SHA256 见 `manifest.json`。后续使用新套件应分配新版本，不覆盖这一套件或旧包。

如果安装器报告校验失败、客户端版本不符、目录已有其他内容或安装中断，请保留报错与独立城院数据目录中的诊断；不会自动卸载旧 DSH、删除已有数据或结束正在运行的任务。已完成的同一套件安装重复运行会核对已有版本，不重新覆盖用户配置。

自定义客户端位置：Mac 可由维护者指定 `QCU_DSH_APP`，Windows 指定 `QCU_DSH_EXE`；需仍为官方 0.2.0-rc.2 客户端。本轮不重建、改品牌或修改官方签名程序。
