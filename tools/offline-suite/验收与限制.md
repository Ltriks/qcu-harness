# 验收与限制

## 本轮已验证（2026-10-20）

- macOS Apple Silicon：官方应用签名通过；使用官方应用内运行时、全新包缓存，安装十个固定包；冷进程导入十个模块，并从官方 Skills 注册表读取七项技能正文。
- Windows x64：官方安装器及应用签名均为 Valid；在 Windows 11 ARM64 虚拟机的 x64 仿真环境中完成同样的安装、导入和技能读取。尚未在原生 x64 电脑验收。
- 两平台测试均对安装父进程及实际 pnpm 子进程安装 TCP/DNS/HTTP 网络阻断；确认子进程阻断生效且没有记录到联网尝试。重复运行同一套件安装保留用户配置；原生飞书 CLI 均可输出1.0.84。
- 以上是客户端内运行时与技能提供方的 CLI 检查。双击安装入口、原生 GUI 启动、实际模型回答、飞书授权读取、WorkBuddy 手工导入和教师试用仍待接收人验收。

## 新环境检查

1. 使用没有旧 DSH 包缓存的新测试配置。安装客户端与运行 `02-install-QCU` 时，无需连接 Hub、npm 或其他包仓库。
2. 安装后检查 `qcu-offline-install.json`：十个产品名称和版本与套件清单一致。失败时没有“安装完成”回执；保留诊断。
3. 若选择启用教学预设，在新启动的城院环境中确认七项 Skill 和 QCU 市场已加载；包和组件开关分别核对。课程工作台、飞书按官方设置单独启用。
4. 先用“备课教案”设计20分钟纸笔百分比变化课程，核对总时长恰好20分钟、目标与评价对应、100到110为10%、110到100约为-9.09%。回答需要当前会话模型，并由教师复核。
5. 正常退出，使用专用启动入口重开，确认插件和本人设置保留；不要把“关闭窗口”当成已退出进程。

## 功能限制

- 本套件离线安装与模型效果验收分开。七项 WorkBuddy Skill 的实际上传、发现和回答效果仍按其附带验收表记录。
- 飞书工具自带 CLI，但本人登录与读取文档需联网；未配置账号或文档时，安装成功不代表文档读取已成功。
- 工作台冻结为已发布1.2；其真实内容质量、教师试用与生成文档在目标 Office 的表现仍需验收。未把1.3本地候选的合成测试当成1.2或本套件的真实生成证明。
- 官方客户端的首次界面确认、许可证、账号/密钥输入由使用者完成。本工具不替代客户端原生安装、签名或权限流程。
- 验证记录会区分应用内运行时/插件加载、原生 GUI、实际官方安装器交互、模型输出与教师效果。某一层通过不能替代其余层。

构建与双平台检查的实际结果见套件旁交付记录。未做过的项目保持待验收，不根据文件存在或导出成功标为通过。
