先把收到的 ZIP 完整解压到一个便于找到的文件夹，再启动助手。不要在压缩包内部直接双击程序。

电脑打开方法
Mac适用于 Apple Silicon（M 系列芯片）、macOS 13 及以上。双击 QCU助手.app。也可把整个 APP 放入“应用程序”。
Windows本包仅为 Mac rc4.1 候选，Windows rc4.1 尚未发布。已有 Windows rc3 用户请继续使用原包及其随包说明。

看到教学首页，以及侧栏的课程工作台、插件市场、专家团，就已进入本套件。七项教学技能、课程工作台、飞书只读工具、插件市场和专家团均已预装，无需老师手动搬运插件包或使用终端。

“离线预装”是什么意思？

应用、技能和这份指南已在包里；使用云端模型回答问题仍需联网、配置模型账号和可用额度。套件不含本地模型权重或公共 API Key。

不必卸载旧 DSH。测试前先保存工作并正常退出旧版，避免同时打开两套助手。本版使用独立的 rc4.1 数据目录，不会自动导入旧版密钥、聊天或工作文件。如需保留旧环境，请由维护人员先核对、预览并确认迁移；首次在本版配置自己的模型。已在本版配置且能够回答时，可直接跳到第一次备课。

界面可能先显示英文。左下角 Settings → General → Language 可选择中文；中文界面对应“设置 → 通用 → 语言”。本手册同时标出常用英文名称。

配置自己的 API Key

API Key（API 密钥）是让助手使用你所选模型服务的凭证。它不是登录密码，也不是一段提问。下面以本版本内置的 DeepSeek 为例，只需首次配置；学校已提供个人配置的，按学校说明操作。

  1. 在服务商平台创建自己的密钥

    联网打开 DeepSeek 开放平台的 API keys 页面（联网），由本人完成注册或登录，再创建 API Key。复制新密钥，核对平台账户是否有可用额度。模型调用按服务商规则计费，网页聊天账号的权益不应直接当作 API 额度。

    平台页面可能改版；找不到密钥或学校统一配置不明时，先请维护人员协助。

  2. 回到 QCU助手的“模型”设置

    点击助手左下角 设置 / Settings → 模型 / Models，在 DeepSeek 项目点击 编辑 / Edit。如果首次弹出“添加一个 API Key 开始使用”，可直接在该窗口填写。

  3. 粘贴密钥，保留默认地址并保存

    把完整密钥粘贴到 API 密钥 / API key，不要加引号、空格或换行。内置 DeepSeek 的 API 地址 / API URL保持“提供商默认”；如需核对，该入口使用 https://api.deepseek.com/anthropic。

    点击 保存 / Save；首次引导窗口则点击 保存并继续 / Save and continue。设置中显示“API 密钥已配置 / API key configured”说明已保存，接下来仍需发一句话验证连接。

    地址要与协议匹配。

    本版本内置 DeepSeek 使用 Anthropic Messages 兼容接口。其他教程里的 https://api.deepseek.com是另一种接口地址，勿直接替换到此入口。地址依据：DeepSeek 官方 API 文档（联网）。

  4. 选择模型，发一句话验证

    关闭设置，进入 新会话 / New Session。在输入框旁的模型选择器中选择已配置的 DeepSeek 模型，发送下面这句。能收到实际回答，才说明密钥、网络和模型可一起工作。

    连接测试，会调用模型
    你好，请只回答“连接成功”。

    若列表为空或模型不可用，请先核对密钥及模型目录；不要随意填写模型 ID。ID 需与提供商当前目录一致。收到报错时看错误提示对照。

我使用其他模型服务，或学校提供的接口请备齐 API 密钥、API 地址、API 协议和模型 ID

在“模型 / Models”中点击 添加模型提供商 / Add model provider。内置目录有你的服务商时，选择“第三方模型提供商”，按该服务商文档填写密钥。

学校网关、自部署服务等，选择“自定义模型 API / Custom model API”。请让维护人员提供完整的接口地址、协议、模型 ID、个人密钥，逐项填写；自定义接口至少需要一个模型。显示名称可以自定，模型 ID 不可随意改写。支持的协议不同，地址写法也不同，不能只替换密钥。

课程工作台使用助手的默认模型，与某一会话单独选中的模型可能不同。工作台模型不可用或显示不符合预期时，让维护人员核对默认配置。

密钥只填在助手设置里

这份 HTML 只负责说明，没有密钥输入框，不保存或上传个人信息。不要把密钥发到聊天、群聊、截图或教学资料中，也不要把配置后的个人数据目录重新打包给别人。误泄露时，到原服务商平台停用该密钥、重新创建，再更新助手设置。

请给出分分钟安排、教师提问、学生任务、预期作品、评价方式及2分钟退出检测。总时长必须为20分钟。
全部使用合成例子，未知条件先向我确认。
  1. 确认技能被加载。查看回答过程中的“加载技能 / Load skill”记录，确认名称是 qcu-lesson-planning。只看到一份通用教案，不能证明专属技能已加载；可追问“请先读取并使用该技能，再按要求修订”。仍未加载，交维护人员核对预装技能是否启用。

我要做什么 → 给谁用 → 有哪些资料 → 有什么限制 → 希望得到什么形式。告诉助手缺少的信息，比只说“帮我备课”更容易得到合用的草案。

课程设计工作台

侧栏的 Course Studio 会打开“课程设计工作台”。需要从资料生成并保存课程成果时使用它；无需新建对话，也无需重新安装插件。

  1. 选工作区，创建一门课程

    先在助手侧栏建立或选好工作区；进入工作台，在“DSH 工作区”选择它，填写“新课程名称”，点击“创建课程”。工作区是你保存成果的地方，没有可选项时请维护人员协助建立。

  2. 加入资料，写清学习目标

    至少选一份自己有权使用的匿名参考资料。支持 TXT、MD、CSV、DOCX、PPTX；每份不超过8 MB，提取文字不超过60,000字符，合计不超过240,000字符。PDF、扫描件和旧 DOC/PPT 不支持，可改用自己核对过的文字摘录。

  3. 先选一个小成果，再确认生成

    首次建议只选“导学案”或“退出检测”，填写学习目标、时长和输出语言。生成前核对参考内容、所用模型及本次选择，确认后再点击生成；所选资料会交给已配置的模型，可能产生调用费用。

  4. 预览、修订，再明确保存

    阅读草案，修改后先“应用修改”，再查看保存位置并明确保存。成果保存在所选工作区的 Course Studio/<course_id>/ 下。看到预览不等于文件已经保存，以保存结果为准。

工作台还可生成 PPT、HTML 幻灯片、思维导图、复习卡、分层作业和互动测验。交互几何、二次函数图像、板书布局、微课脚本、易错点和数学文化等属于实验组件，先少量试用并核对内容。

换任务时重新选资料。

参考资料只临时保留，30分钟后过期；一次生成后会消费本次参考选择，重启或新任务都需要重新选择。超时、断连或结果未确认时，先查看原任务，不连续点击生成；需要重启处理的任务请维护人员协助。

插件市场与专家团

侧栏“插件市场”只打开市场页面，“专家团”只打开专家页面；打开页面不会安装插件或调用模型。先选择需要的能力，再查看说明、来源、权限和预览，确认后按页面提示执行。安装、升级或启用须本人明确确认，新增组件不会因重新打开助手而自动启用。

专家团请先选择有权限的工作文件夹，浏览专家和任务，核对上下文与预览后，再确认生成。模型生成使用本人配置的模型和额度，结果需教师审核。不要把密钥或未经授权的师生资料放进任务。

选读：读取一篇飞书文档

这是可选工具，第一次备课可以跳过。模型的 API Key 与飞书授权是两件事；飞书工具需要本人账号授权，并明确指定一篇允许读取的文档。

  1. 请维护人员协助完成本机飞书授权，在插件设置中核对“本机 CLI 路径”和“授权文档链接”。套件已包含所需工具，老师不必自行安装命令行软件。
  2. 文档链接需为飞书的 /docx/ 或 /wiki/ 链接，去掉问号参数和井号锚点。表格、多维表格和云盘文件夹不适用。
  3. 在会话中提出：“请用飞书只读工具列出已授权文档的目录，先不要读取正文。”待看到目录后，再明确指定一个章节读取。
  4. 工具先列目录，再读指定的一节；不写入、删除或扫描其他文档。更换链接后需要重新列目录。

需要向维护人员说明时，可提供工具名 qcu_feishu_outline 与 qcu_feishu_section。本手册未将真实飞书账号授权或读取标为已验收。

模型连接的错误提示

看到的提示先做什么
401 / 认证失败核对是否为所选服务商的有效 API Key，是否漏字或多了空格；必要时到服务商平台重建密钥，再在助手内更新。
402 / 余额不足查看对应 API 平台的账户额度。学校统一账号请联系维护人员处理。
429 / 请求过多暂停连续发送，稍后再试；不要反复点击。
500、503 / 服务异常或繁忙稍后再试；持续出现则记录时间与错误码，交维护人员核对。
无可用模型 / 地址或模型报错核对所选提供商、API 地址、协议和模型 ID 是否配套；不要照搬另一个入口的地址。
网络错误 / 一直无响应确认电脑能访问所用模型服务；截图保留错误提示，交维护人员检查。课程工作台先查原任务状态，避免重复生成。
