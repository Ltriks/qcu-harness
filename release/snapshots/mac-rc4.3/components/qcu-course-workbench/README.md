# Course Design Studio · 课程设计工作台

官方 DSH 0.2.0-rc.2 插件本地候选 **0.1.0-pilot.1.3**（未部署；历史 1.0/1.1/1.2 保持不可变）。教师选择参考资料与学习目标，使用自己的 DSH 默认模型生成课堂活动草案，审阅修订后保存到明确选定的 DSH 工作区。中英界面，成果可选英文、中文或双语。

默认不启用；通过官方插件页独立确认安装、再确认启用。侧栏 **Course Studio** 打开工作台，不需要新建会话。先在 DSH 建立工作区，在工作台中选定它并创建课程。成果位于该工作区 `Course Studio/<course_id>/`，业务记录在 `.qcu-course-workbench/state.json`。不使用任意路径作为读取授权。

支持 TXT、Markdown、CSV、DOCX 和 PPTX；每份 ≤8 MB、提取文字 ≤60,000 字符，共享参考文字上限 240,000 字符。仅提取正文，不读取宏、外链、批注、图片或公式对象。PDF、扫描件、旧 DOC/PPT 不受支持，应提供经核对的文字摘录。勾选的参考内容和课程目标仅在确认“生成”后发送给官方模型服务。插件不读取或储存 API Key。默认模型须先在 DSH 设置中配置，调用可能产生费用。

参考资料只存 Host 内存，30 分钟过期，按课程隔离，一个任务消费后不可复用；重启或新任务须重新选择。课程、任务、教学草案及保存回执留在所选工作区，不包含原参考文件。模型输出可能复述原资料，请按资料权利管理本地草案。上限为每工作区100门课程、100个任务、1000次保存，达到上限会停止新建，不自动清理用户文件。

14项组件：PPT、HTML翻页、导学案、思维导图、复习卡、分层作业、退出检测、互动测验，以及标注实验性的交互几何、二次函数图像、板书布局、微课脚本、易错点、数学文化。交互几何只支持可拖动三角形，函数图像只支持二次函数滑杆；选择前请核对适用性。Word/PPT由本地 OOXML 模板输出，HTML离线且无CDN。PPT预览显示同一内容的HTML排版，最终Office排版仍须在目标软件核验。

模板配置在官方插件设置的 `frameworkJson` 中，以 JSON 填写：`school`、`stages`、`pathways`、`alignments`、`competencies`、`careerLinkRequired`。默认不启用AP/MCAA/portfolio；未知枚举和被禁字段拒绝。能力维度为概念、技能、思维、语言、价值、生涯；这些是可配置设计标签，不代表任何学校或考试机构认证。无需教学资料时不使用生成任务；本候选至少要求一份匿名参考资料。

预览 → 可修订 → 应用修改 → 查看保存位置 → 明确保存。重名默认另存新版本；覆盖须核对现有文件摘要。重复同一请求不会创建第二个任务或重复保存。超时/断连进入未确认状态，只核对原任务，不自动重试。Host退出时未完成任务标记 restart-required，不自动恢复；停用释放UI/Remote/Skill并停止自身任务，已保存成果不删除。Host代码使用应用用户权限，不是OS沙箱。

候选 1.1 为新失败任务保存固定原因码、阶段、结束类型、有界计数及可选的白名单标准失败码（仅为观测分类）；技术诊断默认折叠，不保存提供方原始错误或响应正文。历史 `model-incomplete` 仅说明具体原因未记录，不推断为组件过多。不调整模型路由、12000 令牌预算或输出上限，不接受失败时的部分草案；收到 stop 后再收到任何块均按流协议失败拒绝。

本次重写采用直接工作台任务：不暴露对话生成工具、不创建代理会话、不执行模型代码，不复用旧版本的两个工具协议和全局禁用清单。包内 `qcu-course-draft` Skill 只介绍工作台使用流程，安装仍不授予文件覆盖或模型调用的额外权限。

本地构建：`node hub/plugins/qcu-course-workbench/build.mjs`；打包：`python3 hub/plugins/qcu-course-workbench/pack.py <输出目录>`。运行相关测试与浏览器预览见仓库 `docs/qcu-course-workbench-validation.md`。未声明实际模型效果、教师试用、Windows或正式发布通过。

候选 1.2 通过官方能力元数据为当前精确路由选择 low，其次 off，否则保留并展示适配器默认推理策略。发送确认绑定路由、策略和 12000 输出预算；能力不可用时禁止新生成，变化时要求重新核对确认。生成使用官方一次性 prepared call 锁定适配器与默认值，不修改用户全局设置，不重试。提示词只包含已选组件规则，限制篇幅并保留完整答案、双语和所有选择；资料不裁剪，严格草案校验不变。详见 `docs/qcu-course-bounded-generation.md`；1.2 的单次真实生成与已知问题见 [原生验收](../../../docs/qcu-course1.2-native-acceptance.md)。1.3 只做离线与合成浏览器验证，见 [稳定性验证](../../../docs/qcu-course-review-stability.md)；未部署、未验证目标 Office。
