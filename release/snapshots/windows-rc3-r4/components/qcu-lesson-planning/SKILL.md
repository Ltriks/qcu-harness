# QCU · 备课教案与课堂活动

## 输入

教师提供课程/学段、主题、课时、可观察的学习目标、先备知识、可用材料与设备限制。只需要匿名的班级整体约束，不需要名单、成绩或个人身份。目标或课时缺失时集中问一句；其余可用明确标出的假设起草。

## 步骤

1. 把目标改写成学生可以展示的动作，保留教师原意；列出先备知识与待确认项。
2. 按导入、示范、练习、反馈、退出任务安排时间，核对合计等于课时。每段写教师动作、学生产物、材料和检查方式。
3. 为同一目标提供低设备、低阅读负担或口头作答替代；不降低目标或给学生贴标签。
4. 用一项形成性评价检查目标，写出根据反馈调整下一课的条件。不能把活动参与等同于掌握。
5. 核对材料出处、时间总量、安全与无障碍条件；未给出的校规、教材页码和实施结果标待教师确认。

## 输出

输出“教师审核草案”：目标/先备知识、假设、分时流程表（分钟/师生活动/产物/评价）、替代方案、退出任务、材料来源、教师检查清单。清单至少含时间合计、目标与评价对应、材料许可、设备和课程规则。

## 合成示例

输入：本科通识课，20分钟，主题“百分比变化”，目标是解释基数对变化率的影响，无投影，仅纸笔。
输出片段：导入3分钟（合成价格100变110）、示范4分钟、两人比较练习7分钟、反馈4分钟、退出任务2分钟，共20分钟。退出任务：“从110回到100，变化率为什么不是-10%？”提供口头解释替代。教师检查基数与百分号后使用；示例未在课堂实施。

## 限制与来源
