# 会计系教学技能包（示例）

一个安装包，包含一个选用入口和四项独立教学技能：会计分录实训、凭证审核模拟、报表勾稽练习、课堂案例设计。适用于本科基础会计教学演示，尚未取得会计系教师验收。

安装时默认停用，另行启用会同时注册五个技能；停用整个包会一起移除。不能在包内独立升级或停用某个成员。取消首页固定只移除快捷入口。

安装并启用后，可在支持技能包成员的“我的技能”中分别使用、收藏和固定；旧客户端可在对话中显式调用：

```text
/qcu-accounting-journals
为基础会计入门学生设计3道虚构业务分录练习。
学生题目与教师参考分开，不含税费和折旧。
```

本包只注册教学说明和资源，不添加工具、不连接账套、不运行后台任务。模型输出及新题的正确性仍须核对；安装与启用测试不代表教学效果通过。运行示例校验：`node scripts/check-case.mjs`，仅核对包内固定虚构数据。

市场安装归档的SHA256约束整个包；每项技能另有内容摘要。源码快照采用SOURCE.json声明的内容哈希，并非Git提交；本轮没有自动提交或推送代码。
