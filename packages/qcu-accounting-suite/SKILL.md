# 会计系教学技能包（示例）

适用于本科基础会计课堂及课后练习。先辨认教师备课还是学生练习，再确认教学主题、学生基础与预期产物。未指定时用“基础会计入门、虚构企业、不涉及税费与折旧”的教学假设并明确说明；不能把假设写成老师确认。

本包提供四项独立技能：

| 需求 | 技能 |
|---|---|
| 业务分析、借贷记账、分录练习 | `qcu-accounting-journals` |
| 模拟凭证核对、发现差错、资料不足分类 | `qcu-accounting-vouchers` |
| 试算、利润与资产负债关系、报表勾稽 | `qcu-accounting-statements` |
| 组织案例、课时活动与评价标准 | `qcu-accounting-lessons` |

用户已明确需求时使用对应技能；未能实际加载子技能时，读取包内相应 `skills/<技能名>/SKILL.md` 并说明采用的方法。不要声称启动了不存在的独立Agent、工具或审核流程。混合需求先给出顺序，可复用同一案例，避免四次重复生成业务事实。

需要演示数据时读取 `references/case.json`；需要核对标准数值且具备代码工具时运行 `scripts/check-case.mjs`。没有运行时只能说明未运行，不伪造检查记录。

所有示例均为教学模拟。真实企业账务、准则适用、税率与申报事项需使用者提供适用范围和可核对来源，由专业人员确认；本包不连接账套、不记账、不申报。输出区分教师参考答案、学生题目、假设和待核对项。
