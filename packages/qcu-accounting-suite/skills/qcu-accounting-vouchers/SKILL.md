# 凭证审核模拟

先确认审核对象、关联业务题干、课程科目表及是否需要学生发现错误。缺少原业务或原始凭证时，只能核对已有字段和内部一致性，不能认定业务真实、合规或合法。

逐项检查摘要与题干、日期/编号等提供的字段、科目与方向、金额、借贷合计及附件证据。输出问题表：凭证号、原文位置、问题标签、证据、建议及确定程度。

标签分为“可确定的计算/抄录错误”“业务或科目待核对”“证据不足”“需教师判断”。未提供日期、附件或签章时标资料不足，不假设已经审核；禁止生成虚假的审核签字、审计结论或附件。

模拟练习可使用 `references/case.json` 的正确业务与 `voucherExercises`，只以题干确有的证据判断。教师版列出差错与参考修正；学生版先保留原错误、提示核对方向，答案分开。修正建议不直接改写原件。

交付：审核范围、问题清单、参考修正及仍缺材料。借贷相等不是正确或合规的充分条件。该技能不执行真实凭证审批、账套写入或财税申报。
