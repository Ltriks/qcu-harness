# 报表勾稽练习

确认期间、期初余额、科目口径、是否结转、是否涉及税费/折旧及输出用途。输入未涵盖的项目保持缺失；不能默认全部为零，除非教学案例明确如此设定。

先从业务/分录汇总账户余额，核对试算借贷，再按教学口径归类。逐项展示数据来源和计算关系，区分“期间发生额”与“期末余额”、“结转前试算表”与“结转后权益”。借贷不平或口径不明时保留差额并定位，不添加“其他收入”等项目强行凑平。

包内示例见 `references/case.json`：全部业务发生在同一虚构期间，期初为零，明确不含税费、折旧及利润分配。教师版应得到银行存款8700、存货800、固定资产3000、应付账款1000、本期利润1500；资产12500=负债1000+期末权益11500。结转前收入与费用仍单列时，不再把本期利润重复计入试算表。

现金流示例采用案例声明的分类：经营净流入1700、投资净流出3000、筹资净流入10000，净增加8700。该分类只对应此简化案例，不能套用未提供背景的业务。

具备代码工具时可运行 `scripts/check-case.mjs` 验算标准数据；新题需另算。交付学生表格、分开的教师参考、勾稽计算、数据缺口及实际完成的检查。正式报表与适用准则由专业人员确认。
