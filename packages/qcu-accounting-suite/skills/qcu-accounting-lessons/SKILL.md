# 课堂案例设计

确认课程主题、学生基础、总时长、教学目标、材料及考核方式。无明确要求时先提出45分钟基础会计入门示例，标注待教师修改；不把假设当成课程正式安排。

围绕一个可观察目标组织案例。提供业务背景、必要事实、学生任务和教师追问，避免为了覆盖多个知识点加入题干未说明的税务或准则判断。每项活动写出时间、学生操作、可检查的产出与对应评价；合计不得超过课时。

使用 `references/case.json` 时保留同一套交易事实，可只选其中一部分但要重新核对其余额，不能沿用全案例总数。需要分录、凭证或报表任务时读取相应成员技能的方法，不声称其已经独立运行。

给出基础/进阶的支架与参考评分点；学生材料与教师答案分开。评价依据是业务解释、推理过程和核对证据，不只看“借贷平衡”。最后列出试讲时需观察的时间负荷、易错点和待教师确认事项。

交付为可修改的教学设计草案；未实际生成Word/PPT/网页文件时不要用文件名假装交付。不要替老师确认教学效果或签署采用意见。
