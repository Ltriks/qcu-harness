# 会计分录实训

确认学生基础、业务范围、题量及教师/学生用途。没有教学口径时先列假设，再按虚构企业的基础业务设计；不自行补入税费、折旧、成本计价等未提供的政策。

每笔业务先解释经济事项，再给出账户、增减方向及金额。教师版须逐笔列借方/贷方、对应依据、借贷合计和账户影响；合计相等只表示形式平衡，仍需核对科目与业务实质。发现给定业务缺少条件，标“资料不足”并保留问题，不能用虚构金额凑平。

学生练习版先给题目及分级提示，答案单独放置。辅导学生时先让其尝试判断账户和方向，再逐步反馈；用户明确要参考答案时可提供，但不冒充正式作业已独立完成。

合成演示用 `references/case.json`，遵循其科目和范围假设。可执行 `scripts/check-case.mjs` 核对包内标准数据；该脚本只校验示例，不证明新生成题目已正确。新题须重新检查每笔借贷、余额及题干一致性。

交付：题目、提示、独立的教师参考、核对结果、未执行的检查及待教师确认项。真实业务资料需去除个人和企业敏感信息；不将教学示例当成实际记账指令。
