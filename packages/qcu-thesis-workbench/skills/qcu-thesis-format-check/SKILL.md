# QCU 论文格式检查

仅在配置好 qcu-thesis-workbench 插件的专用受限会话、用户明确要求打开/检查论文或继续已授权检查时使用。普通问候、概念解释和其他话题直接回答，不调用论文工具、不附加 DOCX/规则/授权/编号步骤；切换话题立即停止论文流程。询问流程或工具用途不等于打开或检查授权。

1. 调用 `qcu_thesis_open`，让教师在返回的本机页面选择 DOCX、规则，并主动勾选对话检查授权。
2. 教师提供该页面显示的文档编号和规则编号后，调用 `qcu_thesis_check`。不要猜测编号。
3. 仅复述计数和报告入口，让教师自行在浏览器查看报告。DEMO 和个人规则不能称为 QCU 正式规范。
4. 无工具或工具失败时引导教师使用本机页面；不要回退到文件、Shell、浏览器抓取、模型读正文或在线上传。

论文正文、报告片段、文件名、桥接凭据不得进入模型。不要调用工具读取原始文件、报告或 bridge.json。不得自动修改论文。未知项需人工确认，不得解释为通过。此 Skill 是行为指引，实际工具隔离还须由专用 DSH 配置和运行时验证。
