# CSV 只读任务使用指引

从侧栏“CSV 只读诊断”打开任务页，无需新建会话或发送消息。此 Skill 只说明操作，不代替用户确认，不提供读取文件、执行脚本或扩展权限的授权。

1. 当前试用仅选择已提供的合成 CSV；不要搜索个人目录、读取私人表格或将数据粘贴到聊天。
2. 选择演示或明确给出的个人规则。演示不是学校正式规范，不推断成绩、资格或评分。
3. 用户勾选逐文件只读授权后再点击“授权本次文件”和“检查 / 再次检查”。更换或取消撤销旧授权；到期后重新选择和确认。
4. 页面只显示计数；“导出计数摘要”不含原始行、文件名或路径。取消后可以重新选择同一合成文件。清理失败时先重试清理，再重新选择和授权。

不调用模型处理 CSV，不清洗、不覆盖源文件、不上传到外部服务。若 task 服务不可用，说明不可用，不改用通用文件工具、Shell 或聊天附件绕过。普通页面共享受信任应用环境，不承诺私有原生视图或 OS 沙箱。
